# How to get started with no setup required

Did you know that you can start programming in python today, without any downloading or installing?  

This is possible through the use of Jupyter Notebooks.  Specifically, we will be looking at using [Google Colab](https://colab.research.google.com/).  

## What Is Google Colab?
It allows you to write and execute Python in your browser and stores your file in your google drive.  This is great for those who is just starting out or wanting to share their work with others.
